Built for Google Chrome on Windows and Linux. The automation runs locally in Chrome and uses Chrome tabs, storage, downloads, and Google Labs Flow access.

What it can do

Flow Automator keeps the existing extension workflow intact.

  • Add one prompt or paste a complete list.
  • Pause, resume, remove, and restart queue items.
  • Choose delay, quality, image count, and auto-download settings.
  • Track progress and countdowns while a queue is running.
  • Open Flow and check project connection status.

Install locally

Download the ZIP, extract it, and load the extracted folder in Chrome.

  1. Download the Flow Automator ZIP from this page.
  2. Extract the ZIP to a normal folder on your computer.
  3. Open chrome://extensions in Google Chrome.
  4. Enable Developer mode in the top-right corner.
  5. Click Load unpacked and choose the extracted folder.
  6. Open Google Flow, then launch the extension from Chrome.
