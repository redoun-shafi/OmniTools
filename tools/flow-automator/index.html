Queue prompts and automate bulk AI image generation in Google Labs Flow.

More prompts. Less repetition.

The extension runs beside Google Labs Flow, keeps your prompt queue organized, and handles the repetitive steps while you focus on the creative direction.

Open Google Flow View other tools
This page is hosted on GitHub Pages. The automation itself requires the Chrome extension because it uses Chrome tabs, storage, downloads, and Google Labs Flow access.

What it can do

Flow Automator keeps the existing extension workflow intact.

  • Add one prompt or paste a complete list.
  • Pause, resume, remove, and restart queue items.
  • Choose delay, quality, image count, and auto-download settings.
  • Track progress and countdowns while a queue is running.
  • Open Flow and check project connection status.

Install locally

Chrome loads the extension directly from the project folder.

  1. Download or clone the OmniTools repository.
  2. Open chrome://extensions in Chrome.
  3. Enable Developer mode.
  4. Select Load unpacked and choose the Flow Automator folder.
  5. Open Google Flow, then launch the extension.

Flow Automator version 3.0.0. Requires Google Chrome and access to Google Labs Flow.
