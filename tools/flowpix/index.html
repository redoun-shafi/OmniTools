Built for Google Chrome on Windows and Linux. The automation runs locally in Chrome and uses Chrome tabs, storage, side panel, and debugger access to Google Flow.

What it can do

FlowPix AI keeps prompt queues fast and simple.

  • Add one prompt or paste a complete list.
  • Queue prompts with a steady 5-second cadence.
  • Choose the delay between prompts in settings.
  • Pause, resume, clear done, and stop the queue.
  • Live status: Connected, automation running, generating photo.

Install locally

Download the ZIP, extract it, and load the extracted folder in Chrome.

  1. Download the FlowPix AI ZIP from this page.
  2. Extract the ZIP to a normal folder on your computer.
  3. Open chrome://extensions in Google Chrome.
  4. Enable Developer mode in the top-right corner.
  5. Click Load unpacked and choose the extracted folder.
  6. Open Google Flow, then launch the extension from Chrome.
